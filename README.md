# image-brightness-contrast-tkinter
A Python Tkinter app to adjust image brightness and contrast
This project is a Python desktop application built using Tkinter.
It allows users to adjust the brightness and contrast of an image in real-time
and save the modified image.
To create a simple GUI application that helps users enhance images by
adjusting brightness and contrast easily using sliders.
